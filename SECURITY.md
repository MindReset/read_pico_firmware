# Security Policy

Report suspected vulnerabilities, exposed private data, or firmware behavior that could cause unsafe power, charging, battery, or display operation privately to [security@mindreset.tech](mailto:security@mindreset.tech), following the [official responsible disclosure policy](https://dot.mindreset.tech/docs/security_policy).

Include the affected commit or release, component, hardware revision if known, impact, and safe reproduction details. Remove credentials, full device identifiers, and personal content. Do not publish vulnerability details in issues or pull requests before a fix is available.

Ordinary bugs, documentation corrections, and non-sensitive hardware questions belong in the [issue tracker](https://github.com/MindReset/read_pico_firmware/issues/new/choose). See [Support](SUPPORT.md) for other help.

# Security Policy

For this independent firmware, use this repository's **Security → Report a vulnerability** feature when available. If private reporting is not enabled, open an issue requesting a private contact channel without posting exploit details or private data. MindReset's official security address is for their products and upstream project, not for this fork.

Include the affected commit or release, component, hardware revision if known, impact, and safe reproduction details. Remove credentials, full device identifiers, and personal content. Do not publish vulnerability details in issues or pull requests before a fix is available.

Ordinary bugs, documentation corrections, and non-sensitive hardware questions belong in this repository's issue tracker. See [Support](SUPPORT.md) for other help.

# Support

For build, flashing, driver, display, sleep/wake, or documentation problems in this repository, read the [README](README.md) and search existing issues, then [open an issue](https://github.com/MindReset/read_pico_firmware/issues/new/choose).

Include the firmware commit or release, ESP-IDF version, host OS, board revision if known, configuration changes, reproduction steps, and relevant redacted serial logs or photos. For display or power issues, include the refresh profile and USB/battery power state. Mark unknown or untested details explicitly.

For purchases, repairs, accounts, or the Dot App, use the [official contact channels](https://dot.mindreset.tech/docs/contact). Do not post order details, full device identifiers, or personal content in public issues. Report vulnerabilities privately through [Security](SECURITY.md).

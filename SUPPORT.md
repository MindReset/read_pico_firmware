# Support

For build, flashing, driver, display, sleep/wake, or documentation problems in this independent firmware, read the [README](README.md) and search this repository's issues, then open a new issue here.

Include the firmware commit or release, ESP-IDF version, host OS, board revision if known, configuration changes, reproduction steps, and relevant redacted serial logs or photos. For display or power issues, include the refresh profile and USB/battery power state. Mark unknown or untested details explicitly.

For purchases, repairs, accounts, or the Dot App, use the [MindReset official contact channels](https://dot.mindreset.tech/docs/contact). Do not post order details, full device identifiers, or personal content in public issues. Report vulnerabilities through [Security](SECURITY.md).

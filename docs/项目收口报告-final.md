## 三、审计①：harness 解耦（失败短路掩盖流变）

**问题**：`reader_settings_panel_host_test.py` 的 `run_c` 原用 `check=True`，行为用例非零退出抛 `CalledProcessError`，吞掉 stdout 的 digest 行 → digest 比对永远不执行，「行为红 + 流变」被静默屏蔽。

**修复**（随 C2 提交）：去掉 `check=True`，改返回 `(stdout, stderr, returncode)`；`main()` **先取 digest 行比对，digest 通过后再查 `rc!=0` 上报行为失败**。digest 比对与行为断言解耦。

**负向验证**（已通过）：注入 `return fail("injected behavior fail");` 替代 `return 0;` → 输出 `reader_settings_panel: digest OK (81dffeaf94d63657) but behavior/on-screen case FAILED` + `case FAIL: injected behavior fail` → 确认 digest 先比对、行为后报。还原后正常 PASS。

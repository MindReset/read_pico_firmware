Pico-Plus 墨水屏极客副屏固件 · 网页刷机

适用硬件：MindReset RDP-G01-W 墨水屏阅读器（ESP32-S3）

本固件为第三方修改版：基于 kiikoread r95 版（0.3.3-rc95）改造，四大卖点—— 双栏排版（横屏一页两栏，翻页次数减半）、 离线词典与生词本（取词查义，无需联网，词典文件需自备）、 蓝牙推流（安卓手机把长文与单词卡推到设备，当极客副屏用）、 网页刷机（无需安装任何软件，浏览器一键烧录）；与 MindReset 官方无关。

一键刷机

用 USB 数据线连接设备后，点击下面的按钮开始。

如果之前刷过官方固件，工具会提示擦除全部数据——这属于正常现象 （官方固件与本固件的分区布局不同，必须整片擦除后才能写入），确认即可。
刷机脚本没能加载出来（网络原因）。请更换网络环境后刷新本页重试； 脚本来自 jsdelivr / unpkg 两个公共 CDN。

操作步骤

  1. 用 USB 数据线把设备连接到电脑（部分充电线只能充电，不能传数据）；
  2. 确保设备电量充足（建议 50% 以上）；
  3. 点击上方 「安装固件」 按钮；
  4. 在弹窗中选择设备对应的串口（如 COM3、USB JTAG/serial debug unit），点击连接；
  5. 等待进度条走完（约 1～2 分钟），设备自动重启，刷机完成。

手机端配套 App（蓝牙推流用）· 仅安卓

刷完固件后，若要使用手机蓝牙推送（副屏），请下载配套安卓 App： ReadPicoPush.apk （也可到仓库 apk/ 目录或本版 Release 附件下载）。

  • 仅支持 Android（安卓）；不支持苹果 iOS（系统限制）。
  • Android 10/11 手机：需在系统设置里打开「定位服务」并授予位置权限，否则扫描不到设备（App 顶部会有红字提示）。
  • 固件与 App 必须同时更新：旧版 App 在有多台设备并存时可能连到非目标设备。

刷完之后必做：放置离线词典

本固件不包含词典数据。查词功能依赖放在 TF 卡里的词典文件， 不放置则无法使用查词功能。
  1. 下载词典文件 dict.bin （约 8.9 MB，推荐；需要更全词库可下载 dict-full.bin 并重命名为 dict.bin）；
  2. 把文件命名为 dict.bin，复制到 TF 卡根目录下的 dict 文件夹里： 在电脑上打开 TF 卡盘，在最上层建一个 dict 文件夹，把文件放进去 （不需要建 sdcard 文件夹——设备内路径 /sdcard/dict/dict.bin 里的 /sdcard 只是固件中 TF 卡的挂载点名， 卡插到电脑上看到的就是卡盘根目录本身）；
  3. TF 卡插回设备并重启，之后阅读时选中单词即可查词。

文件名称与位置必须严格一致：dict.bin 放在 TF 卡根目录的 dict 文件夹下，其他名字或位置不生效。详细说明见仓库 README 第四节。

常见问题

按钮点了没反应 / 找不到串口？换一根数据线、换一个 USB 口，并关掉其他可能占用串口的软件。

页面一直转圈或按钮不出现？是刷机脚本没加载出来，换个网络环境重试。

提示浏览器不支持？必须使用电脑版 Chrome 或 Edge 浏览器；暂不支持手机浏览器和 Safari。

烧到一半失败？重新插拔 USB 后重试；反复失败可换数据线或换 USB 口。

刷完为什么查不了词？词典文件没放。本固件不包含词典数据， 需按上方「刷完之后必做」把 dict.bin 放进 TF 卡根目录的 dict 文件夹（设备内路径记为 /sdcard/dict/，无需建 sdcard 文件夹）。

刷完想升级/重刷？可以再次使用本页面；也可以把 Read_Pico.bin 重命名为 Pico-update.bin 放到 TF 卡根目录，在设备上「设置 → 升级和恢复」中安装 （注意：相同版本会被设备拒绝重装，此时请用本页面重刷）。
